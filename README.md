# 2048 Game

A browser implementation of the classic 2048 puzzle game. Slide numbered tiles across a 4x4 grid, merge matching tiles, and try to reach the 2048 tile before the board fills up.

## Live Preview

Experience the live website: [2048 Game Demo](https://egorfomin419.github.io/2048_game_portfolio/)

## Design Reference

Based on the original game: [play2048.co](https://play2048.co)

## Technologies Used

- **HTML5** — page markup
- **SCSS** — styling
- **JavaScript (ES Modules)** — game logic and DOM rendering
- **Parcel** — bundler and dev server
- **ESLint / Stylelint** — code quality and formatting
- **GitHub Pages** — hosting and deployment

## Getting Started

1. Clone the repository:

```
git clone https://github.com/egorfomin419/2048_game_portfolio.git
cd 2048_game_portfolio
```

2. Install dependencies:

```
npm install
```

3. Run the project locally:

```
npm start
```

## Features

- **Classic 2048 Gameplay**: merge tiles with matching numbers to reach the 2048 tile.
- **Keyboard Controls**: move tiles with the arrow keys (Left, Right, Up, Down).
- **Score Tracking**: current score updates live as tiles merge.
- **Game States**: start screen, win message, and lose message with a restart option.
- **Smooth Animations**: new tiles and merges are visually highlighted on the board.
- **Responsive Layout**: playable on different screen sizes.
